# Login SENATI

Interfaz de inicio de sesión adaptable a escritorio y móviles, construida con HTML, CSS y JavaScript sin dependencias externas.

## Ejecutar
Abre `index.html` en un navegador.

## Importante: autenticación
Este proyecto contiene la interfaz y validación básica de campos. **No autentica usuarios ni almacena sesiones**. Para producción, conecta el formulario a un backend HTTPS que valide las credenciales, gestione sesiones seguras y aplique protección contra CSRF y fuerza bruta. Nunca guardes contraseñas en el frontend ni en el repositorio.

El enlace de ayuda es un marcador de posición y debe ajustarse al canal oficial de soporte correspondiente.
